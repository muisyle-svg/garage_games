Edition configuration

Events & hardware

— events

Set each event’s starting points, minimum, points lost per step, seconds per step, and initial grace period. Fields marked default follow edition scoring; an inherited minimum follows the global minimum, while an event with its own starting points defaults to half that value rounded up. Grace sets the first loss time: with 10 seconds grace and 5 seconds per step, losses occur at 10, 15, 20 seconds, and so on. With zero grace, the first loss remains after one full interval. Points stop decreasing at the minimum. Physical availability is unverified until a fresh scan completes; virtual event presses remain available when hardware is missing or unassigned.

Clear this app’s database

This removes all competitors, queue entries, runs and event results, messages, edits, selected-player state, and device status. The database schema and configured devices remain; devices return to their default ready state. An automatic timestamped backup is created first and kept in the database’s backups folder.
